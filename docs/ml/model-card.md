# Model Card

## Общая информация

[Ссылка на Hugging Face](https://huggingface.co/yashpwr/resume-ner-bert-v2)

**Название модели**:

Resume NER BERT v2

**Источник**:

Hugging Face

**Автор**:

yashpwr (более подробной информации об авторе нет)

**Задача модели**:

Выделение именованных сущностей, интересующих нас при парсинге резюме (таких как ФИО, ключевые навыки, место обучения и т.д).

**Язык**:

Только английский

## Использование в проекте

Модель может быть использована для массового парсинга резюме из открытых источников для формирования начальной базы данных кандидатов. 

Система может предлагать кандидатов не только из загруженных пользователями резюме, но и из более широкого списка.

## Входные данные

Текст резюме. Если резюме, например, в PDF, придётся достать из него текст.

## Выходные данные

Разметка именованных сущностей. Типы:

- Имя и фамилия

- Email

- Телефон

- Локация

- Предыдущие места работы

- Должности

- Навыки

- Число лет опыта работы

- Уровень образования

- Название учебного заведения

- Год окончания обучения

## Метрики качества

- F1: 90%

- Precision: 91%

- Recall: 90%

Стоит учитывать, что на странице модели не указано, как и на каких датасетах производилась оценка. Можно предположить, что использовалось стандартное разделение на train и validation.

## Ограничения

- Модель понимает только английский язык.

- Модель обучена в основном на резюме работников технического и бизнес-характера.

- До 512 токенов.

- Не очень высокие метрики вследствие маленького датасета и размеров модели.

## Не рекомендуется использовать

Модель годится только для грубой обработки данных. Для извлечения более качественных признаков придётся использовать что-то другое.
