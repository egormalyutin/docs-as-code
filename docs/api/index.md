# API

API предоставляет доступ к функциям сервиса по анализу резюме с помощью ИИ.

## Основные операции

- `POST /cvs/upload` - загрузить резюме;

- `POST /cvs/analyze` - запускает анализ резюме;

- `GET /cvs/analyses/{id}` - получает статус анализа и результат, если анализ готов;

- `GET /cvs` - позволяет посмотреть загруженные резюме.

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
