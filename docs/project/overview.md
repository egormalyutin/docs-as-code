# Анализатор резюме

Сервис автоматически анализирует загруженное резюме: извлекает ключевые данные об опыте, навыках и образовании, сравнивает их с требованиями вакансии и формирует оценку соответствия. Проект помогает сократить время первичного скрининга, повысить объективность отбора и дать соискателю обратную связь по резюме.

**Основные пользователи**:

- рекрутер или HR-специалист;

- менеджер по найму;

- соискатель.

**Основные функции**:

- загрузка резюме и описания вакансии;

- извлечение и структурирование информации из резюме;

- оценка соответствия кандидата требованиям вакансии;

- формирование рекомендаций по улучшению резюме;

- просмотр результатов анализа и экспорт отчёта.

## Комплект документации

1. Описание проекта - общая информация, предназначена для всех.

2. Требования - общая информация, предназначена для всех.

3. Архитектура системы - нужна для тех, кто будет продолжать разрабатывать систему и заниматься её развёртыванием. Эта документация поможет разобраться во внутреннем устройстве системы.

4. Документация API - нужна для тех, кто будет продолжать разрабатывать систему, а также для сторонних пользователей API. Эта документация позволит понять, что от системы ожидают другие разработчики.

5. Документация ML-модели - нужна для тех, кто будет заниматься продолжением разработки самой ML-модели. Позволит понять, какие датасеты и готовые модели были использованы.

6. Руководство пользователя - предназначено для всех. Желательно, чтобы система была интуитивной для пользователя, однако не всегда это просто или достижимо.

7. Руководство для развёртывания и администрирования - позволит понять, как корректно развернуть систему и не снести базу данных.
