# Требования

## User stories

### US-01. Структурирование резюме для рекрутера

Как рекрутер,

я хочу видеть извлечённые из резюме опыт, навыки и образование в структурированном виде,

чтобы быстрее оценивать кандидата без ручного чтения всего документа.

**Критерии приёмки**:

- после загрузки резюме отображаются отдельные блоки "Опыт", "Навыки" и "Образование";

- отсутствующие в резюме данные помечаются как "не найдено";

- рекрутер может открыть исходный текст резюме рядом с извлечёнными данными.

### US-02. Просмотр и экспорт отчёта для менеджера по найму

Как менеджер по найму,

я хочу открывать сохранённый результат анализа и экспортировать отчёт,

чтобы обсуждать кандидата с командой на основе единого документа.

**Критерии приёмки**:

- в списке анализов отображаются сохранённые результаты с датой и названием вакансии;

- на странице результата видны оценка соответствия, ключевые совпадения и рекомендации;

- отчёт можно экспортировать в PDF или CSV.

### US-03. Анализ резюме соискателем

Как соискатель,

я хочу загрузить резюме и описание вакансии и получить оценку соответствия,

чтобы понять свои сильные стороны и пробелы перед откликом.

**Критерии приёмки**:

- система принимает резюме в форматах PDF или DOCX и текст описания вакансии;

- после обработки отображаются оценка соответствия и 2-3 рекомендации по улучшению резюме;

- если файл не удалось прочитать, пользователь видит понятное сообщение об ошибке и результат не формируется.

## User cases

### UC-01. Оценка соответствия резюме кандидата требованиям вакансии

**Актор**: рекрутёр

**Цель**: быстро получить оценку соответствия резюме кандидата требованиям вакансии, чтобы принять решение о дальнейшем рассмотрении кандидата.

**Предусловие**: рекрутёр выбрал вакансию с описанием требований и загрузил резюме кандидата в поддерживаемом формате.

**Основной сценарий**:

1. Рекрутёр открывает карточку кандидата и выбирает вакансию для сравнения.

2. Система проверяет формат файла резюме и извлекает текст.

3. Система структурирует данные резюме: опыт, навыки, образование.

4. Система выделяет ключевые требования из описания вакансии.

5. Система передаёт структурированные данные резюме и требования вакансии ML-модели.

6. ML-модель определяет оценку соответствия, ключевые совпадения и пробелы.

7. Система сохраняет результат в карточке кандидата и отображает его рекрутёру.

8. Рекрутёр видит оценку соответствия, список совпадений и недостающих требований, а также рекомендацию по дальнейшему шагу.

**Альтернативный сценарий**:

Если файл резюме не удаётся прочитать или извлечённого текста недостаточно для анализа, система сообщает об ошибке и предлагает загрузить другой файл или передать кандидата на ручной просмотр. Результат автоматической оценки не формируется.

**Результат**: оценка соответствия резюме кандидата требованиям вакансии сформирована и сохранена в карточке кандидата либо рекрутёр получил понятное сообщение об ошибке и возможность передать кандидата на ручную обработку.
